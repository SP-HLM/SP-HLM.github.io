# SP-HLM


**Sparse-Pose-Driven Motion Generation and Whole-Body Control for Humanoid Loco-Manipulation**


Project page: https://sp-hlm.github.io/


## Source and original-quality videos


Page source is at the repository root. `assets-images.zip` contains the image assets under `assets/`. The complete website and original-quality videos are preserved in [the site-v1 release bundle](https://github.com/windydauy/SP-HLM/releases/tag/site-v1). No video re-encoding or quality reduction is applied.


Extract the complete bundle and run `python3 preview.py` for local preview.


## Deployment


Run **Publish project page** under Actions using the **main** branch. The workflow extracts the complete bundle, applies the current HTML/CSS/JavaScript and image assets from this repository, and deploys to GitHub Pages.


## Design


Layout references include [BFM·TTC](https://bfmttc.github.io/), [UniT](https://xpeng-robotics.github.io/unit/), [BeyondMimic](https://beyondmimic.github.io/), [LucidSim](https://lucidsim.github.io/), and [HumanPlus](https://humanoid-ai.github.io/), particularly their title and author sections, video presentations, method figures, and experiment layouts. Independently implemented for SP-HLM. Research figures and videos belong to this project.
