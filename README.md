# SP-HLM

**Sparse-Pose-Driven Motion Generation and Whole-Body Control for Humanoid Loco-Manipulation**

Project page: https://windydauy.github.io/SP-HLM/

## Website source and original-quality videos

The complete, self-contained website (HTML, CSS, JavaScript, figures, and original-quality demonstration videos) is available as `SP-HLM-project-page.zip` in the **site-v1 release**. Extract it and run `python3 preview.py` for a local preview.

The main page source is also included at the repository root. `assets-images.zip` contains the image assets under `assets/`. The videos remain in the complete release archive because the main video exceeds GitHub's regular Git file-size limit. No video re-encoding or quality reduction is applied.

## Deployment

The Pages workflow downloads the complete site bundle from the site-v1 release and deploys it to GitHub Pages. Run **Publish project page** under Actions to redeploy the same version. To publish updates, replace the release archive with a revised bundle, then run the workflow.

Layout inspired by https://bfmttc.github.io/; independently implemented for SP-HLM. Research figures and videos belong to this project.
